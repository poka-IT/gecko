Create `lib/providers/cert_alert_provider.dart` with three elements:

1. **`CertAlertStatus` enum** with values: `none`, `expiringSoon`, `expired`. Document each value with `///` comments in English.

2. **`certAlertStatusProvider`** -- a synchronous `Provider.family` parameterized by `({String address, CertDirection direction})`:
   - Watch `certificationListProvider((address: params.address, direction: params.direction))`
   - If `certState.isLoading` or `certState.certifications.isEmpty`, return `CertAlertStatus.none`
   - Iterate certifications: for each cert where `cert.expireDate != null`:
     - If `DateTime.now().isAfter(cert.expireDate!)` -> set `hasExpired = true`, break (worst status, short-circuit per D-04)
     - If `cert.expireDate!.difference(DateTime.now()).inDays <= 30` -> set `hasExpiringSoon = true` (per D-03, only expired and <=30 days trigger alerts)
   - Return `CertAlertStatus.expired` if hasExpired, `CertAlertStatus.expiringSoon` if hasExpiringSoon, else `CertAlertStatus.none`
   - Document: "Computes worst-case cert alert status for an address. For home wallet tiles: use CertDirection.received. For contact entries: use CertDirection.sent."

3. **`contactCertAlertProvider`** -- a synchronous `Provider.family<CertAlertStatus, String>` parameterized by `contactAddress`:
   - Watch `walletsListProvider` to get all owned wallets (per research recommendation: check ALL owned wallets, not just primary)
   - For each wallet in `walletsState.wallets`:
     - Watch `certificationListProvider((address: wallet.address, direction: CertDirection.sent))`
     - Filter `certState.certifications` where `cert.address == contactAddress` (the `address` field in sent certs is the receiver -- the contact)
     - Apply same threshold logic: expired -> return immediately, expiringSoon -> track worst
   - Return worst status found across all wallets
   - Document: "Checks if the current user has any sent cert to contactAddress that is expired or expiring soon, across all owned wallets."
