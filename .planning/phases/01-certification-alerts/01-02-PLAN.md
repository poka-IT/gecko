The `CertAlertDot` widget uses `certAlertStatusProvider` internally (address + direction), but for contacts we need `contactCertAlertProvider` which checks sent certs across ALL owned wallets (per D-05). So create an inline helper method instead of using `CertAlertDot` directly.

Add a private helper method to the `ContactsList` class:
```dart
Widget _buildContactAlert(BuildContext context, WidgetRef ref, String contactAddress) {
  final alertStatus = ref.watch(contactCertAlertProvider(contactAddress));
  if (alertStatus == CertAlertStatus.none) return const SizedBox.shrink();
  final color = alertStatus == CertAlertStatus.expired
      ? context.geckoColors.danger
      : context.geckoColors.warning;
  return Padding(
    padding: EdgeInsets.only(right: scaleSize(8)),
    child: Container(
      width: scaleSize(8),
      height: scaleSize(8),
      decoration: BoxDecoration(
        shape: BoxShape.circle,
        color: color,
      ),
    ),
  );
}
```
