1. `cesiumNameProvider` -- a `FutureProvider.family<String?, String>` keyed by address:
   - Import `package:flutter_riverpod/flutter_riverpod.dart` and `package:gecko/providers/cesium_profile_provider.dart`
   - Watch `cesiumProfileProvider(address)` to reuse the existing cached profile fetch (no extra HTTP call)
   - Extract the `'title'` field from the profile map
   - Filter out null, empty string, and the literal `'Duniter Wallet'` (this default is set by `saveCertificationQueue` and is meaningless)

   - Add English doc comment: `/// CesiumPlus name provider: returns the self-declared name for [address], or null.`

2. `cesiumNameConflictProvider` -- a `FutureProvider.family<String?, String>` keyed by address:
   - Import `package:durt2/durt2.dart` as `d` (for `SquidService`)
   - Watch `cesiumNameProvider(address).future` to get the CesiumPlus name
   - If csName is null, return null immediately (no conflict possible)
   - Call `d.SquidService.client.searchAddressByName(csName)` to search on-chain identities
   - Iterate results: if any result has `result.name.toLowerCase() == csName.toLowerCase()` AND `result.address != address`, return that conflicting address
   - Return null if no conflict found
   - Wrap in try/catch, return null on error (graceful degradation when Squid is unavailable)
   - Add English doc comment: `/// Detects if a CesiumPlus name conflicts with an existing on-chain identity on a different address.`
